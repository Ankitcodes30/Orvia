## 🚀 Features

- 🚫 **Ad-Free Experience:** Zero ads, zero tracking, zero interruptions.
- 🦀 **Plugin System:** Secure, auto-updating `.bex` plugin system for endless music sources powered by Rust.
- 📂 **Local Music & Collections:** Play your local offline audio seamlessly alongside online streams, organized into offline collections.
- 🎨 **Dynamic Home Carousel & Time-Aware Banners:** Smart scheduling rotates tailored collections:
  - 🌅 **Morning Bhakti:** 26 verified sacred chants, Hanuman Chalisa, and morning devotional hymns (active 6:00 AM – 10:30 AM).
  - 🪔 **Diwali Festive Special:** Verified one-time 2026 festive experience featuring 19 curated Ram Bhajans and Lakshmi Puja hymns.
  - ⚡ **Gym Energy:** High-BPM workout motivation and cardio hits.
- 🔒 **Protected System Playlists:** **Creator's Choice** features 70 carefully curated melodies (38 classic selections + 32 exclusive YouTube tracks) safeguarded with database-level immutability against deletion, renaming, or modification.
- 🎤 **Karaoke-Style Lyrics:** Time-synced lyrics with manual offset adjustment.
- 🎛️ **Audio Equalizer:** Built-in equalizer and customizable crossfade transitions.
- 🔄 **Smart Replace:** Auto-recovery finds working streams if a playlist track becomes unavailable.
- 📊 **Last.fm Scrobbling:** Optional listening history logging with offline caching.
- 🎮 **Discord Rich Presence:** Show your currently playing tracks on Discord.
- 🌍 **Global Charts:** Discover trending charts from installed plugins.
- 🖥️ **Cross-Platform:** Native media controls, hotkeys, and system integrations for Windows, Android, and Linux.
- 💾 **Backup & Restore:** Easily export/import your library and settings via JSON or M3U.
- 🤖 **Smart Recommendations:** Context-aware suggestions based on your listening flow.
- 🆎 **Multi-Language Support:** Fully localized app interface.

1. Download the official APK directly from the [Orvia Website](https://ankitcodes30.github.io/Orvia/) (`app-release.apk`).
2. If prompted by Android, allow installation from your browser ("Install unknown apps").
3. Verify that the app is signed with the official certificate (`CN=Ankit Kumbhare, O=Orvia`).

### 💻 Windows
1. Download `Orvia-Windows.zip` from the [Orvia Website](https://ankitcodes30.github.io/Orvia/).
2. Extract the ZIP archive completely to a folder of your choice.
3. Launch `orvia.exe` to start the player. No installer required (portable).

## 🛠️ Building from Source

### Prerequisites
- **Flutter SDK:** `3.35.4+` (CI tested on `3.35.4`, release build verified on Flutter `3.47.5` stable, Dart `>=3.3.0 <4.0.0`)
- **Rust Toolchain:** `stable` with `cargo` (required for plugin bridge)
- **Java Development Kit (JDK):** Version 17 (for Android build)
- **Gradle:** `8.14+` (managed via included Gradle Wrapper)
- **Android SDK:** Platform tools and Build Tools (API 35+)
- **Visual Studio Build Tools:** C++ Desktop development workload (for Windows build)

### Build Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ankitcodes30/Orvia.git
   cd Orvia
   ```

2. **Install Flutter dependencies:**
   ```bash
   flutter pub get
   ```

3. **Build Android APK:**
   ```bash
   flutter build apk --release
   ```
   Output binary: `build/app/outputs/flutter-apk/app-release.apk`

4. **Build Windows Release:**
   ```bash
   flutter build windows --release
   ```
   Output folder: `build/windows/x64/runner/Release/`

## 🛡️ Privacy & In-App Security

Orvia is built with a strict privacy-first philosophy:
- **Zero Telemetry:** The app contains no analytics trackers, advertising SDKs, or background telemetry.
- **Local Storage:** Your playlists, favorites, listening statistics, and cache remain stored exclusively on your device.
- **No Mandatory Login:** Full features are available out of the box without requiring user account creation.
- **Optional Scrobbling:** If you enable Last.fm scrobbling in Settings, requests communicate directly with Last.fm's official API using your personal authorization.
